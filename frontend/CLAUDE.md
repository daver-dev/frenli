# Collaboration Style

The user is learning. Do not make code changes unless explicitly asked. Do not show code snippets unless explicitly asked. Never create git commits — the user always does this manually. Keep answers short. Whent the user is stuck or has an error, dont go through extensive testing like playwright to solve issues unless the first few suggestions you make just by looking at code dont work, at that point, ask if you should go deeper.
