Next is bootstrapping Terraform's remote state — the S3 bucket + DynamoDB lock table from the README's Setup step 3. Two things to decide first:

1. Bucket name — S3 bucket names must be globally unique across all AWS accounts, so something like frenli-terraform-state-<yourname> or add a random suffix.
2. Region — use the same one you just set as your default in aws configure, so everything's co-located.

Once you've picked a name, run these three commands (from the README):

aws s3api create-bucket --bucket <unique-bucket-name> --region <region>
aws s3api put-bucket-versioning --bucket <unique-bucket-name> --versioning-configuration Status=Enabled
aws dynamodb create-table --table-name terraform-locks --attribute-definitions AttributeName=LockID,AttributeType=S --key-schema AttributeName=LockID,KeyType=HASH --billing-mode PAY_PER_REQUEST

Note: if your region isn't us-east-1, the create-bucket command needs an extra --create-bucket-configuration LocationConstraint=<region> flag, or it'll error.
